# sezgialtan.com

Personal portfolio of **Sezgi Altan** — software developer building web and mobile experiences.

**Live at [sezgialtan.com](https://sezgialtan.com)**

## Stack

- [Next.js](https://nextjs.org) (App Router, Turbopack)
- [React](https://react.dev) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)
- [Framer Motion](https://www.framer.com/motion/) for animations

## Features

- Single-page scroll layout with anchor navigation
- Dark mode by default, with a light/dark theme toggle
- Terminal-style boot intro on first load
- Custom cursor and scroll-triggered animations
- Fully responsive, `prefers-reduced-motion` friendly

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
